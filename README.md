# MLR_Anxiety_Project
A thorough MLR project conducted by myself and peers, studying the relationship between statistics anxiety and other variables.

## Work Summary
- Worked collaboratively to conduct a comprehensive regression analysis to model relationships between math 
anxiety, prior experience,  statistics anxiety, and other school or anxiety-based variables 
- Implemented MLR models with interaction terms to evaluate moderating effects between variables 
- Performed residual diagnostics and model validation in R to assess assumptions, fit quality, and statistical 
significance, translating quantitative results into interpretable insights via a formal technical report 

## File Guide
- MLR_Anxiety_Report.pdf  a formal report containing R findings analysis, conclusions, and reflection
- MLR_Anxiety_Slideshow.pdf  a reformatted medium detailing the same findings as the report
- anxiety_dataset.csv  contains all samples from Kaggle. For formatted variable key, see the anxiety variable key Word document
